# Product

SoloSprint is an Android-only offline running tracker.

Core Features:
1. Run tracking (GPS, distance, duration, pace, route).
2. Step counter (works in background when supported by Android sensor/service).
3. Daily/Weekly/Monthly statistics.
4. Weekly/Monthly goals.
5. History list.

Out of scope:
- Login
- Cloud sync
- Social
- Ads
- AI
